📖 WebAssembly Integration Guide

Step 1: Build the Wasm Module

# Push to the wasm branch
git push origin wasm

# Wait for CI to complete
# Download artifacts from GitHub Actions

Step 2: Include Wasm Files in Your Web App

<!-- Include the generated files -->
<script src="video-compare.js"></script>
<!-- The .wasm file will be loaded automatically -->

Step 3: Initialize the Module

// Wait for module to load
VideoCompareModule().then((module) => {
    console.log('Wasm module ready');
    
    // Load images into virtual filesystem
    module.FS.writeFile('/left.png', leftImageBytes);
    module.FS.writeFile('/right.png', rightImageBytes);
    
    // Call the main function
    module.ccall('load_images', 'number', ['string', 'string'], 
                 ['/left.png', '/right.png']);
});

Step 4: Display on Canvas

// Emscripten will create a canvas automatically
// Or you can render to your own canvas:
const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');

// Get image data from Wasm
const imageData = module.ccall('get_image_data', ...);
ctx.putImageData(imageData, 0, 0);

Expected File Sizes

  • video-compare.wasm: ~1-2MB (optimized)
  • video-compare.js: ~50-100KB (loader)
  • video-compare.html: Generated by Emscripten (optional)

Browser Requirements

  • WebAssembly support (all modern browsers)
  • SharedArrayBuffer (for multi-threading, optional)
  • HTTPS required for SharedArrayBuffer
